# Интеграция StrategyLab с живым бэкендом

- Настроены Vite proxy `/api` → `127.0.0.1:8001` и одинаковый origin для авторизации с cookie.
- В `src/api/real.ts` добавлен адаптер REST-контрактов Python к типам UI.
- Списки теперь читаются из обычных массивов, статусы поддерживают `queued/running/done/failed`.
- Авторизация использует живые login/me/logout; конфигурации читаются и редактируются как YAML.
- Поддержаны создание конфигурации на серверном шаблоне и запуск анализа по числовому config_id.
- Подключены детали этапов, сводка с аналитическим verdict, блоки, проверки и фоновой rerun.
- Реестр заявок и Decision X-Ray получают реальные `drilldown`, изменения и исходные JSON/XML.
- Реальные ограничения REST API отмечены в интерфейсе и BACKEND_REQUESTS.md, неподдерживаемые функции не имитируются.
- Сохранена существующая дизайн-система, исключены `node_modules` и IDE-артефакты.
