# StrategyLab · фронтенд, подключённый к FastAPI

Это **реальный React + TypeScript + Vite интерфейс** для репозитория `vishnya-balance-pl`, на основе текущего дизайна StrategyLab. Моки для работы не нужны.

## Как установить на Windows (PowerShell)

1. Запустите бэкенд **из корня backend-репозитория**:

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
   ```

   Если у вас другое окружение Python, используйте команду Никиты `py -m uvicorn ...`.
   FastAPI Swagger: http://127.0.0.1:8001/docs.

2. Распакуйте этот архив **в папку `frontend/` общего репозитория**. `package.json` должен находиться непосредственно в этой папке:

   ```text
   vishnya-balance-pl/
   ├─ backend/
   ├─ configs/
   ├─ frontend/
   │  ├─ package.json    ← ЗДЕСЬ
   │  ├─ vite.config.ts
   │  └─ src/
   └─ requirements.txt
   ```

3. В **другом** терминале откройте папку с фронтендом:

   ```powershell
   cd C:\Users\Maksi\Downloads\vishnya-balance-pl-main\vishnya-balance-pl-main\frontend
   npm install
   npm run dev
   ```

4. Откройте http://127.0.0.1:5173. Введите любое имя длиной до 64 символов (как требует `/api/login`).

5. Если списка пресетов ещё нет, зайдите в **Конфигурации анализа → Создать из шаблона**. Проверьте `dataset.path` в YAML (он должен вести к данным на машине, где запущен FastAPI). После сохранения можно создавать запуск из «Истории запусков» или «Конфигураций».

**Не выполняйте `npm install` из корня репозитория с бэкендом.** `package.json` находится в `frontend/`.

## Куда отправляются запросы

Браузер обращается к относительному пути `/api/*` на Vite (`http://127.0.0.1:5173/api/*`). Vite перенаправляет запросы на **http://127.0.0.1:8001**. Это особенно важно для `HttpOnly`-cookie авторизации.

Если бэкенд использует другой порт, создайте файл `.env` на основе `.env.example`:

```dotenv
VITE_BACKEND_URL=http://127.0.0.1:8001
```

После изменения `.env` перезапустите `npm run dev`. Для **продакшена** Vite-прокси не действует: настройте проксирование `/api/` до FastAPI на вашем reverse proxy, желательно на том же домене, что и фронтенд.

## Подключено

- `POST /api/login`, `GET /api/me`, `POST /api/logout` — вход и восстановление сессии;
- `GET /api/configs`, `POST /api/configs`, `PUT /api/configs/{cid}` — пресеты в YAML; создание с шаблоном по умолчанию;
- `GET /api/pools`, `GET /api/procedures` — справочники;
- `GET /api/runs`, `POST /api/runs`, `GET /api/runs/{rid}`, `GET /api/runs/{rid}/steps/{step}` — запуски и этапы;
- `GET /api/runs/{rid}/summary`, `/blocks`, `/checks`, `POST /checks/rerun` — аналитический отчёт и проверки;
- `POST /api/runs/{rid}/drilldown`, `GET /api/runs/{rid}/apps/{app_id}`, `/raw` — реестр заявок и Decision X-Ray.

UI преобразует ответы, потому что реальные FastAPI-списки возвращаются **массивами**, а не `{items,total}`. Статусы: `queued`, `running`, `done`, `failed`; конфигурации приходят строкой `yaml`, не объектом `config`; исходные документы приходят по ключам `BEFORE_MASTER`/`AFTER_BETA`.

## Проверка перед Git

```powershell
npm run test
npm run build
```

Внутренние тесты проверяют REST-адаптер на контрольных ответах, не подключаясь к локальному FastAPI. Для end-to-end проверки **требуется работающий сервер** и датасет на вашем ПК.

Файлы `node_modules/`, `dist/`, `.env`, `.idea/` игнорируются через `.gitignore`.

## Ограничения реального API

- `GET /api/runs` возвращает запуски **всех пользователей**, а детали доступны любому авторизованного имени; backend нужно доработать для публичного деплоя. Login без пароля — только для локального/хакатонного использования.
- Нет стабильного `dataset_id` или публичного снапшота YAML у `GET /api/runs/{rid}`. UI показывает пустой ID, а путь из **текущей** конфигурации используется только как подсказка (не гарантия исторического датасета).
- `POST /drilldown` отдаёт список без пагинации и без `QUALITY_ISSUE`. Для ~2002 заявок UI загружает весь список и фильтрует решение/причину локально. Признак качества помечается как недоступный, не имитируется.
- Backend не умеет фильтровать `drilldown` по блокам данных: кнопка перехода из таблицы блоков временно отключена.
- `POST /checks/rerun` лишь отправляет фоновую задачу и отвечает `{ok:true}`; используйте «Обновить», чтобы загрузить готовые результаты.
- Выполнение нового анализа может завершиться ошибкой, если `dataset.path` на сервере не существует. Фронтенд не загружает файлы на сервер.
- Пока не настроены права доступа, копирование ссылок на чужие запуски намеренно отключено.

Подробнее: `BACKEND_REQUESTS.md`.
