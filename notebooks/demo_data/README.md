# Публичные примеры для ноутбука

Четыре пары из раздела samples материалов задания (all_context_combined.txt).
Файлы с суффиксом _bef переименованы в APP_ID.json в BEFORE_MASTER, парные
файлы без суффикса помещены в AFTER_BETA. Содержимое JSON не изменено.
manifest создан для этого демонабора, исключения взяты из публичного manifest.

Это небольшой набор для воспроизводимого запуска без полного датасета.
Он не представляет статистику всех 2002 заявок. Организаторские expected-файлы
и отложенные данные сюда не включены. Чтобы проверить свою версию датасета,
укажите DATASET_PATH в первой ячейке параметров pipeline.ipynb.
