# Локальный запуск: проверка снимка 36d1f08

Пакет исправлений подготовлен по `spr-current.zip` от 8 ноября 2026. Это точечный патч к указанному снимку, не замена репозитория. Новые исправления P0-07 от Анжелики в пакет не включены.

## Что исправлено

1. Vite proxy и `.env.example` направляют `/api` на `127.0.0.1:8000`, как `run.ps1` и `run.sh`. Сообщение об ошибке подключения и frontend README согласованы с этим портом.
2. «Создать из шаблона» получает полный YAML через `/api/configs/template`. Ранее кнопка отправляла только имя, а сервер создавал пустую заготовку и проверял ещё не настроенный путь. При создании шаблона откладывается только проверка доступности датасета; запуск по-прежнему валидирует путь.
3. Чтение raw BEFORE/AFTER локального запуска поддерживает внешний датасет из snapshot конфига. В staging сохраняется ограничение каталогом `data`; в обоих режимах стороны не могут выходить за корень датасета. Владелец и APP_ID проверяются как прежде.
4. Explorer возвращает в `drilldownFilters` неявный `DIFF_FLAG=1`, когда `includeUnchanged=false`. Без него запрос списка мог вернуть неизменённые заявки сверх числа в группе.
5. `npm test` запускает все `tests/*.test.cjs`, включая deep links и объяснения, а не один файл.

Распакуй ZIP в корень. Он содержит патч, этот README, новый тест и обезличенный протокол API-прогона. Существующие исходники заменит только `git apply`.


Если `--check` сообщил конфликт — не выполнять следующую команду и не применять патч повторно. Нужны актуальный SHA и конфликтующие файлы. Новый тест из ZIP также должен находиться в `tests/` при запуске pytest.

Если уже существует `frontend/.env` или `frontend/.env.local`, проверь `VITE_BACKEND_URL`: старое значение `8001` переопределяет новый default. Для штатного запуска укажи `http://127.0.0.1:8000`. Секреты и локальные ENV в коммит не добавлять.

## Запуск Windows

Проверь, что доступны Python, Node.js и npm:

```bash
py --version
node --version
npm --version
```

Если `node` не найден, установи Node.js LTS с npm и заново открой терминал. Одного Python для запуска React недостаточно.

Из корня в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Дождись строки готовности Vite и API. Открой **http://127.0.0.1:5173**. Swagger: http://127.0.0.1:8000/docs. Остановка — Ctrl+C в окне запуска.

Альтернатива: два окна Git Bash/PowerShell с уже установленными зависимостями. В первом из корня:

```bash
py -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Во втором:

```bash
cd frontend
npm run dev
```

Оба процесса должны использовать доступные зависимости; если они установлены только в `.venv`, для ручного бэкенда используй `.venv/Scripts/python.exe` вместо `py`. Штатный `run.ps1` сам создаёт и использует это окружение.

## Данные и первый запуск

1. Войди под своим именем; открой «Конфигурации анализа» → «Создать из шаблона».
2. Для короткой проверки укажи в YAML `dataset.path: notebooks/demo_data`. Подпапки сторон оставь `RESULTS/BEFORE_MASTER` и `RESULTS/AFTER_BETA`. Это набор из четырёх заявок, эталон 2002/502/385 к нему не относится.
3. Для выданного набора пользователя путь:

```yaml
dataset:
  path: 'D:/Destruction/Nuclear Hack/ХАКАТОН_СИСТЕМА_АНАЛИЗА_ИЗМЕНЕНИЙ/ПАКЕТ/ЗАДАНИЕ/data/RUN-20260827-0001'
  before_dir: RESULTS/BEFORE_MASTER
  after_dir: RESULTS/AFTER_BETA
  formats: [json, xml]
```

Меняется только соответствующая секция полного шаблона, не весь конфиг. Нажми «Сохранить», затем «Запустить с пресетом». Путь указывает на родителя `RESULTS`, а не на сам `RESULTS`.

## Что ещё вернуть фронту по P0

Это замечания по коду присланного снимка, не утверждения о более новых коммитах:

- `Config.tsx`: есть YAML и каталоги, но нет workspace-редактора Python, preview и подключения процедур из UI (P0-02/03/04).
- `Checks.tsx`: нет SOURCE/ARGUMENT, кликабельных APP_ID/полного списка и ожидания завершения job. После приёма rerun предлагается вручную обновлять таблицу (P0-04/07).
- Explorer-дерево работает с заданной раскладкой миграций. Оно не заменяет произвольный выбор rows/cols/filters для сводной P0-05.

До демонстрации отдельно пройти в браузере: вход → создание/сохранение конфига → запуск → отчёт → дерево/реестр → заявка → BEFORE/AFTER → HTML → ссылка обратно, затем F5. P0-07 принять после обновления Анжелики и подключения фронта.
